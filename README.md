# Student Grade Manager

A Python CLI app for managing student grades and calculating average scores.

این پروژه یک برنامه ساده برای ثبت نمرات دانش‌آموزان، نمایش وضعیت قبولی یا مردودی و محاسبه میانگین نمرات است.

## Features

- Add students and their grades
- Display the student list
- Calculate the average grade
- Check pass or fail status
- Validate grades between 0 and 20
- Interactive command-line menu

## Requirements

- Python 3
- No external packages required

## How to Run

```bash
python3 main.py
```

## How It Works

Student names and grades are stored in two lists. The application uses an interactive menu to add students, display their grades, and calculate the average.

اطلاعات فقط در طول اجرای برنامه نگهداری می‌شوند و پس از خروج ذخیره نمی‌مانند.

## Concepts Practiced

- Variables and constants
- User input and output
- Conditional statements
- `while` and `for` loops
- Lists and list methods
- Functions
- Input validation
- Basic calculations

## Limitations

- Data is not saved after the program exits.
- Grades must be whole numbers.
- Student records cannot yet be edited or deleted.
